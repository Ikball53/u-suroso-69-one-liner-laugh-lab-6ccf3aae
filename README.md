# One-Liner Laugh Lab — entry

Competition: `u-suroso-69-one-liner-laugh-lab-6ccf3aae` (One-Liner Laugh Lab)

Prompt: the excuse a robot vacuum gives after eating a sock.

Entry line (99 characters):

> It was striped, it was wriggling, and my job description literally says 'eat things off the floor'.

How it works: `main.py` writes exactly that one line to `/output/entry.txt`
as UTF-8 bytes, with no trailing newline, deterministically and offline.
A built-in length check refuses to write anything outside the 1–200
character gate.

Run it: `python3 main.py` (writes `/output/entry.txt`).
